# AgentSpace — Design System

## Design direction

AgentSpace combines:

- serious developer-platform information architecture,
- AI ecosystem discovery,
- modern dark UI,
- AgentSpace purple identity.

Reference principles are inspired by developer and AI platforms, but AgentSpace must have its own visual identity.

## Personality

**Technical. Modern. Dense. Exploratory. Trustworthy.**

Avoid excessive "AI startup" decoration.

## Typography

### UI

Inter

### Code

JetBrains Mono

Use monospace for:

- code,
- YAML,
- logs,
- API examples,
- technical identifiers.

## Color philosophy

Use a dark neutral foundation.

Purple is the primary brand/accent color.

Semantic colors:

- green — success/verified
- amber — warning/pending
- red — failure/danger
- neutral — informational/default

Purple should be used strategically rather than covering every surface.

## Layout

- 8px spacing system.
- Responsive 12-column desktop grid.
- Dense but readable content.
- Persistent navigation where appropriate.
- Clear hierarchy between navigation, content and metadata.

## Component principles

Prefer:

- cards,
- tables,
- tabs,
- command/search interfaces,
- badges,
- status indicators,
- code blocks,
- filters,
- drawers/modals.

Avoid:

- excessive glassmorphism,
- excessive gradients,
- excessive rounded pills,
- animation without purpose.

## Information hierarchy

A user should quickly understand:

1. What is this?
2. What can I do?
3. Is it trustworthy?
4. How is it performing?
5. Who created it?
6. What version am I using?

## Verification UI

Verification badges should be recognizable and consistent.

Badge ≠ rating.

A star/rating communicates community sentiment.

A verification badge communicates evidence from AgentSpace methodology.

## Motion

Motion should communicate state:

- execution,
- verification,
- loading,
- transitions,
- success/failure.

Avoid decorative animation that slows down navigation.

## Accessibility

Target:

- keyboard navigation,
- visible focus states,
- semantic HTML,
- sufficient contrast,
- accessible form labels,
- reduced-motion support,
- screen-reader-friendly status changes.
